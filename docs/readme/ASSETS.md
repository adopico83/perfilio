# Capturas del README

Los PNG de esta carpeta salen en `README.md`. Los dos primeros ya existen (fotogramas reales de `public/demo_nueva.mp4`). El resto son huecos para que Ander suelte capturas cuando las tenga.

| Archivo | Estado | Qué mostrar |
|---------|--------|-------------|
| `agente.png` | Listo | Sidebar del agente: briefing del día + voz/foto |
| `presupuesto.png` | Listo | Borrador de presupuesto (“dicta por voz”) |
| `landing.png` | Pendiente | Hero de [perfilio.vercel.app](https://perfilio.vercel.app) (escritorio, ~1280×720) |
| `dashboard.png` | Pendiente | Dashboard crema/terracota con obras y métricas |
| `gasto.png` | Pendiente | Flujo ticket/foto → gasto categorizado |

**Formato:** PNG, < 1,5 MB, sin datos personales de clientes reales.

Cuando añadas un archivo pendiente, descomenta su bloque en `README.md` (están marcados).
